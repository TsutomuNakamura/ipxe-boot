# etc/ipxe-image-server
Put files here to override the built-in ones of `ipxe-image-server`.
This directory is mounted on `/etc/ipxe-image-server` of the container `ipxe-image-server`.

* `config.yml`
* `boot.ipxe.j2`
* `templates/`

Refer to "Customize OS installations (optional)" in [README.md](../../README.md) for details.
Files in this directory except this README.md are ignored by git.
